# 决策记录（ADR）

每份记录回答：**当时为什么这么选，什么条件下该推翻。**

## 格式

```markdown
# NNN. 标题

- 状态：提议 / 已采纳 / 已推翻 / 被 NNN 取代
- 日期：YYYY-MM-DD

## 背景
什么问题需要决定，不做的代价是什么。

## 候选方案
A / B / C，各自的代价，不要只写优点。

## 选择

## 理由
具体到证据，不写"感觉更好"。

## 推翻条件
什么观察结果出现时，应该重开这个决定。
**没有这一节的决定不算完成。**
```
